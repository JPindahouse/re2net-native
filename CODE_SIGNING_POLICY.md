# Code signing policy — proposed

No signature or SignPath Foundation sponsorship currently exists for this project.
The maintainer intends to apply for free code signing, with the current prototype
status, absence of public adoption and dependency questions disclosed honestly.
This document does not claim compliance or approval.

Proposed maintainer/author/reviewer/signing approver: GitHub user JPindahouse.
The maintainer must approve these responsibilities and comply with the provider's
account and review requirements personally. No account security setting is changed
by this repository or its build. Every future signing request needs a human approval.

Only original artifacts built from reviewed disclosed source may be proposed for
signing. Upstream loader DLLs, game or Valve binaries and extracted assets must not
be submitted as our own. A signature is not evidence of correct co-op gameplay.

If sponsorship is granted, this page and release pages will name the actual signer
and service as required by its policy. Until then, releases must be described as
unsigned and unapproved. The current workflow compiles only and has no signing
credentials, uploads or release publication step.
